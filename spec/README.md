# Specifications

This repository is data: meaning files, their schema and the format reference
([`FORMAT.md`](../FORMAT.md)). This folder holds proposals for and decisions about
the format, kept in the [SpecScore](https://specscore.md) form.

## Contents

| Directory | Purpose |
|---|---|
| [`decisions/`](decisions/README.md) | Decisions about the meaning-file format: the wording put to the owner, his answer, and what he did not decide |
| [`ideas/`](ideas/README.md) | Proposed format changes not yet decided; an accepted idea becomes a decision record |

An idea or a decision record does not change the format. The format in force is what
`FORMAT.md` and the schema files beside it say (`meaning.schema.json` for
`meaning/draft-1`, `meaning.draft-2.schema.json` for `meaning/draft-2`); a
decision takes effect when they are changed to match it.
