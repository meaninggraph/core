# Specifications

This repository is data: meaning files, their schema and the format reference
([`FORMAT.md`](../FORMAT.md)). This folder holds only the record of decisions about
the format, kept in the [SpecScore](https://specscore.md) form.

## Contents

| Directory | Purpose |
|---|---|
| [`decisions/`](decisions/README.md) | Decisions about the meaning-file format: the wording put to the owner, his answer, and what he did not decide |

A decision record does not change the format. The format in force is what
`FORMAT.md` and `meaning.schema.json` say; a decision takes effect when they are
changed to match it.
